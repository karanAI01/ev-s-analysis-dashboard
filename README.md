# EV-s-Analysis-Dashboard
🚗 Electric Vehicles Analysis Dashboard
An Interactive Power BI Dashboard for Electric Vehicle Market, Manufacturer, Performance & Policy Analysis
### 1.	Project Title / Headline
🚗 Electric Vehicles Analysis: Market, Manufacturer & Performance Insights Dashboard

An interactive Power BI dashboard designed to analyze electric vehicle adoption, manufacturers, models, pricing, electric range, vehicle types, year-wise growth, and Clean Alternative Fuel Vehicle (CAFV) eligibility.

The dashboard transforms raw electric vehicle population data into meaningful visual insights to support market analysis, manufacturer comparison, EV performance evaluation, and policy-oriented analysis.

### 2.	Short Description / Purpose
The Electric Vehicles Analysis Dashboard is an interactive Power BI report developed to explore and understand patterns in the electric vehicle market.

It provides insights into EV adoption trends, vehicle types, leading manufacturers, popular models, pricing, electric range, and CAFV eligibility, allowing users to compare different segments of the EV market through interactive visualizations and filters.

The dashboard is useful for data analysts, automobile companies, EV manufacturers, policymakers, researchers, and business decision-makers interested in understanding the electric vehicle landscape.

### 3.	Tech Stack
The dashboard was developed using the following tools and technologies:

📊 Power BI Desktop – Main platform used to build the interactive dashboard and visualizations.
🔄 Power Query – Used for data cleaning, transformation, and preparation.
🧠 DAX (Data Analysis Expressions) – Used to create calculated measures and analytical metrics.
🗂️ Data Modeling – Used to organize the dataset into dimension and fact tables and establish relationships.
📈 Power BI Visualizations – Cards, bar charts, column charts, donut charts, pie charts, area charts, scatter plots, and slicers.
📁 Data Format – CSV-based source data imported into Power BI.
💾 Power BI File Format – .pbit template for the project.

### 4.	Data Source
The dataset used for this Electric Vehicles Analysis project was obtained from Kaggle, a widely used platform for datasets and data science projects.

The dataset contains detailed information about electric vehicles, including their manufacturer, model, model year, electric vehicle type, electric range, base MSRP, CAFV eligibility, electric utility, VIN, and vehicle ID.

The dataset was imported into Power BI, where it was cleaned and transformed using Power Query and then structured through data modeling. DAX measures were created to perform calculations and generate meaningful KPIs and analytical insights.


### 5.	Features / Highlights
•	Business Problem
The electric vehicle market is growing rapidly, but raw EV datasets can be difficult to interpret because they contain large amounts of information about manufacturers, models, vehicle types, prices, electric range, model years, and eligibility criteria.

Without an interactive analytical dashboard, it can be difficult to answer questions such as:

Which manufacturers have the largest EV presence?
Which EV models are most common?
How is EV adoption changing over time?
Which EV types dominate the market?
How does electric range vary between manufacturers?
Is higher vehicle price associated with greater electric range?
Which manufacturers offer higher-priced EVs?
What percentage of vehicles meet CAFV eligibility requirements?
How are different EV types distributed across CAFV eligibility categories?

The dashboard addresses these questions through interactive data visualization.

•	Goal of the Dashboard
The primary goal is to create an interactive analytical solution that:

Provides a clear overview of the EV population.
Identifies leading EV manufacturers and models.
Analyzes EV growth over different model years.
Compares vehicle pricing and electric range.
Examines different EV types.
Evaluates CAFV eligibility.
Helps identify market and performance patterns.
Allows users to interactively filter and explore the dataset.

•	Walkthrough of Key Visuals
- KPI Cards – Provide a quick summary of important EV market metrics.
- EV Type Distribution – Shows the composition of different electric vehicle types.
- Top Manufacturers – Identifies manufacturers with the highest EV representation.
- Top EV Models – Highlights the most frequently represented vehicle models.
- EV Growth by Year – Shows how the EV population changes across model years.
- Average MSRP by Manufacturer – Enables comparison of vehicle pricing across manufacturers.
- Electric Range by Manufacturer – Compares EV performance based on average electric range.
- Range vs MSRP Analysis – Helps identify the relationship between vehicle pricing and electric driving range.
- CAFV Eligibility Analysis – Examines vehicle eligibility categories and their distribution across EV types.
- Interactive Filters – Allow users to dynamically analyze the dashboard based on selected years, countries, EV types, and other available dimensions.

•	Business Impact & Insights
🚗 Market Analysis

The dashboard enables analysts to identify manufacturers and models with significant representation in the EV market.

🏭 Manufacturer Comparison

Companies can compare manufacturers based on:

EV population
Average MSRP
Average electric range
Vehicle type
💰 Pricing Analysis

The relationship between Base MSRP and Electric Range provides useful insights into EV pricing and performance.

⚡ Performance Analysis

Electric range comparisons help identify manufacturers and vehicle categories offering stronger driving-range performance.

📈 Growth Analysis

Year-wise EV analysis can help identify periods of increased EV adoption and changes in the market over time.

🏛️ Policy Analysis

CAFV eligibility analysis provides insight into how vehicles are classified under alternative-fuel eligibility criteria.
